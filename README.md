# factor-mining-showcase

量化因子挖掘系统的**界面演示**（纯静态，无后端、无网络请求）。

- 线上：<https://factor-mining-showcase.pages.dev>
- 全部数据为**合成数据**，不代表任何真实回测结果。

## 这是什么 / 不是什么

**是**：按设计稿重建的一套界面，用于展示系统的交互与信息组织方式。

**不是**：不是真实系统的代码，不含任何实现逻辑，不含真实因子定义、回测结果或数据源信息。
本仓库是**独立重写**的展示层，与生产代码库无共享代码。

## 构成

```
index.html            外壳：玻璃态头部、主导航、主题切换
assets/styles.css     设计系统（色板 / 组件 / 响应式 / 深浅色）
assets/data.js        合成演示数据 + 图表序列生成
assets/app.js         路由、5 个视图渲染、手写 SVG 图表
```

技术为**零依赖**的原生 HTML/CSS/JS（ES Module），不需要构建步骤。

## 界面

| 页面 | 内容 |
|---|---|
| **因子挖掘** | **精品轨 hero**（三槽注入 · 三层校验链 · 自动改错 · boost 变体）、模式选择、运行参数与进度、运行日志、族包网格、能力扩充、算子目录 |
| 因子库 | 统一索引表格（IC / Rank IC / ICIR / IR / 胜率 / 覆盖 / 换手 + 累积走势迷你图），可排序、按来源筛选、搜索 |
| 数据 | 生效配置、注册表覆盖（表 / 变量数 / 起止 / 天数） |
| 单因子详情 | IC 时序（含面积填充）、累积 IC、分组 PnL、IC 家族指标、字段与算子、**三层校验**（精品轨）、**载体原文语法高亮**、全部指标 |
| 族包详情 | 族说明、注入来源、**载体源码**、分组 PnL、月度 IC 热力图、族内相关矩阵、变体表、日志 |

另有「缓存库」「全局设置」两个弹层，以及深浅色主题。

## 视觉重点：精品轨

精品轨是这套界面的主角，体现在：

- **顶部 hero** 用渐变描边 + 光晕，直接展开该路线独有的三个环节
- **三槽注入**：思路库 / 知识库检索 / 构造范式，各自给出注入内容与条数
- **三层校验链**：静态契约 → 短窗试算 → 前瞻审计，逐层显示通过 / 淘汰与淘汰原因
- **自动改错**：展示回发模型修正的轮次、原因与结果
- **boost 变体**：四层维度（参数 / 参照点 / 聚合 / 掩码）及其采纳状态
- 模式选择默认落在精品轨，参数会随之切换（`n_generations` / `population_size` 禁用）
- 因子库默认展示 23 个精品轨因子；详情页的校验卡与代码块带精品轨专属描边

```bash
python -m http.server 8090

```

## 部署

```bash
npx wrangler pages deploy . --project-name factor-mining-showcase --branch main
```

`robots.txt` 与 `_headers` 已配置 `noindex`，避免被搜索引擎收录。

## 数据说明

数据由固定种子的伪随机数生成，因此每次打开数值一致。指标区间刻意贴近日频因子的现实范围
（IC ≈ 0.015–0.056，ICIR ≈ 0.29–0.92，多空 IR ≈ 0.5–1.7，IC 胜率 ≈ 50–61%），
避免出现经不起推敲的数值。

研究方向的命名取自展示者本人知识库中的 alpha 页，用以体现「知识库参与搜索」这一设计。
